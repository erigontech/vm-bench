vm-bench

How fast erigon executes EVM transactions compared with geth, revm, evmone and Nethermind, on the same state-test fixtures, re-measured on every change to main.

EVM: EEST benchmark blocks

One 150M-gas block per test, run through each client's own blockchain-test tool (geth and erigon evm blocktest, revme blockchaintest, nethtest -b, evmone-blockchaintest). Mgas/s = gas / (wall time of the file − wall time of the same file with no blocks), best of 3. Every client parses the fixture, executes the block and checks the state root, so the number is comparable across clients. Grey = the no-block twin is more than 30% of the run, setup-dominated. Fixtures: EEST benchmark@v0.0.7, 150M variant.
