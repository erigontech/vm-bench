RPC workloads

Request corpora anyone can replay against their own mainnet node: workloads/, one directory per workload with the JSON-RPC bodies, the pinned block and the rate ladder. Open loop at each rate, 20 s; rps below the rate means the node is at capacity; latency in ms; err = failed requests; a node that answers errors to a workload is skipped. Numbers from different machines compare on latency at equal rate and on the knee, not on peak rps.
